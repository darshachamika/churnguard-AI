# ChurnGuard AI

Customer Churn Prediction & Retention Intelligence Platform

## Overview

ChurnGuard AI is an end-to-end machine learning and full-stack
application designed to analyze customer churn and provide
customer-level churn risk predictions.

The project combines data analysis, machine learning, backend
API development, database integration, and a web-based dashboard.

## Problem Statement

Customer churn can have a significant impact on a company's revenue.
The goal of this project is to analyze customer behavior and build
a machine learning system that can predict whether a customer is
likely to churn.

## Dataset

The initial dataset used in this project is the Telco Customer Churn
dataset obtained from Kaggle.

Dataset:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn
